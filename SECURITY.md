## Reporting a Vulnerability

If you discover a security vulnerability, security issue, or accidentally committed credentials within this repository:

1. **Do NOT open a public issue.**
2. Report the vulnerability privately via **GitHub Security Advisories**:
   - Go to the **Security** tab of the repository on GitHub.
   - Click **Report a vulnerability**.
3. Alternatively, you can email: `ly.sari1999@gmail.com`.

We appreciate your responsible disclosure and will respond promptly to investigate and resolve reported issues.
