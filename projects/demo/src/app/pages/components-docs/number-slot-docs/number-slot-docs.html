Number slot

A number whose digits spin like the reels of a slot machine. Each digit that changed travels through the window, blurs while it is fast, slips past its place, and settles. A comma, a dot, or a currency mark stays put. Khmer digits ០–៩ spin the same way and roll through Khmer digits. It is the reel beside numberPopIn, which pops a digit into place instead of spinning it.
