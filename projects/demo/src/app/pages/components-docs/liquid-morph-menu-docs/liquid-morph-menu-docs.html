Liquid morph menu

A row of items with one highlight that pours between them. It grows in on the first item the pointer meets, follows the pointer and the keyboard focus, and drains away when the pointer leaves — from wherever it stands, even mid-pour.

Add pill and it is the header's icon bar: a glass pill of 24px icons, with a count bubble for any item that needs one. Turn it on its side with orientation="vertical", pin it to a selection, or switch it off per item.

Examples

Pill

The header's icon bar. Items that come and go fold the row open and shut, and a count turning up takes the highlight along without a pour. The pinned item keeps the highlight when the pointer leaves.

Pinned by a popup

Bind liquidMorphActive to the popup's isOpen() and the highlight stays on the item that opened it while the pointer moves off to use the panel.

Selection

With disabledHover the highlight ignores the pointer and stays on the pinned item, so it marks a selection and pours only when the selection changes. Keyboard focus still moves it.

Disabled

liquidMorphDisabled keeps the highlight off one item and dims it; crossing it lets the highlight go. disabledHighlight on the menu keeps the highlight away from every item. 

{{ code.disabled }}

Vertical

The same menu as the row, stacked: the items, the pill and the pour are unchanged, only the axis turns. Without pill the menu draws only the highlight; the page styles the items, and sets align-items: stretch for full-width rows.

Custom look

Every tunable is a --liquid-morph-* custom property read with a fallback, so it can be set on the menu or any ancestor. This one is a light text menu with a tinted highlight, a wider reach and a slower pour.
