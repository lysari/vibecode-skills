Pincode Box

Multi-slot numeric OTP and verification code entry with automatic caret advancement, backspace regression, clipboard paste distribution, and verification wave shimmers.

Overview

The Pincode Box splits multi-digit codes into individual input cells while maintaining a unified model string. It supports keyboard navigation, auto-focus, paste distribution, dots masking, invalid error glows, and a sequential wave animation during backend checks.

Formats

The component adapts to 4-digit PINs, 6-digit OTPs, and masked security codes.

4 Digits Compact verification for quick popovers or mobile cards
6 Digits Standard 2FA and OTP authenticator codes
4 Digits Masked Prominent PIN entry for high-security transactions

Setup & Usage

import { PincodeBox } from '@app/shared/components/pincode-box/pincode-box';

@Component({
  imports: [PincodeBox],
  template: `
    <x-pincode-box
      [length]="6"
      [(value)]="otpCode"
      (completed)="verifyOtp($event)"
    />
  `,
})
export class VerificationPage {
  protected readonly otpCode = signal('');

  protected verifyOtp(code: string): void {
    // Process authorization code
  }
}
