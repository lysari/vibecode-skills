Liquid input

The portal's text field: Angular Material's matInput API gathered into one element, with masks, per-character transforms, and a group that draws one box around several fields. The label, the hint and the error belong to the field rather than to a wrapper around it.

Everything below is the component itself, imported the way a page imports it — so this cannot drift from what the app ships. Every value is made up here; nothing is read or saved.

Examples

Label, hint, placeholder

The label is a real <label for>. The hint sits under the field and is named by aria-describedby; optional adds the quiet chip the application form uses.

Masks

0 a digit, A a letter in any script, * either, and every other character a literal that appears as the slots around it fill. The form is handed what was typed, not the separators — maskStores="formatted" says otherwise. 

{{ code.mask }}

Transforms

Each character is handed over as it arrives, and what comes back is what lands. Return null to refuse it. It runs before the mask, so the slot is offered what the transform returned. 

{{ code.transform }}

Clear, reveal, count

The buttons fold themselves into the row and press under the finger, and none of them takes the focus off the field: clearing a field is not leaving it.

Groups, in a form

One box around several fields, each keeping its own mask or picker. A segment is whatever registers itself as one, so an x-liquid-autocomplete is as welcome as a masked field. The value is an object keyed by each segment's name.
