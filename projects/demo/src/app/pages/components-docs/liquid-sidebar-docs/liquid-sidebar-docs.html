Liquid Sidebar

A fluid application sidebar container with smooth icon-rail collapse, glassmorphic surface styling, expandable sub-menus, and branch dropdown menus with tactile liquid response.

Matches the platform sidebar design tokens 1:1 with crisp native vector glyphs, search trigger, expandable navigation branches, and automatic concentric inner radii: inner_radius = outer_radius - padding.
