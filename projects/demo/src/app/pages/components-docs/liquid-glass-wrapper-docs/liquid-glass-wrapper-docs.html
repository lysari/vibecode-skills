Liquid Glass

Apple WWDC-inspired physical glass material featuring ray-traced Snell's law refraction, specular rim highlights, pointer-reactive shimmer, and graceful fallback modes.

Overview

Liquid Glass renders realistic translucent surfaces using generated SVG displacement and specular maps. It refracts underlying images or text with chromatic aberration and adapts dynamically to element resizing. Available both as a container component (<app-liquid-glass-wrapper>) and an attribute directive ([appLiquidGlass]).

Setup & Usage

import { LiquidGlassWrapperComponent } from '@app/shared/components/liquid-glass-wrapper/liquid-glass-wrapper.component';
import { LiquidGlassDirective } from '@app/shared/components/liquid-glass-wrapper/liquid-glass.directive';

@Component({
  imports: [LiquidGlassWrapperComponent, LiquidGlassDirective],
  template: `
    <!-- Wrapper component mode -->
    <app-liquid-glass-wrapper [radius]="28" [bezel]="36">
      <div class="card-body">Interactive surface</div>
    </app-liquid-glass-wrapper>

    <!-- Host directive mode -->
    <div class="my-card" appLiquidGlass [lgRadius]="24">
      <span>Direct glass injection</span>
    </div>
  `,
})
export class GlassShowcase {}
