API Reference

Components and interfaces exported from @app/shared/components/liquid-expand.

<x-liquid-accordion>

Property Type Default Description
items LiquidAccordionItem[] [] List of items to render directly. Supports IFaqItem properties.
value string | null null Currently open key in single mode. Two-way: [(value)].
values string[] [] Currently open keys in multi mode. Two-way: [(values)].
multiple boolean false Whether multiple items may be expanded at the same time.
collapsible boolean true Whether an active item can be toggled closed in single mode.

<x-liquid-expand>

Property Type Default Description
title string '' Title or question text shown on the trigger.
icon string | null null Optional ionicon name rendered in the spring squircle plate.
expanded boolean false Whether this panel is expanded. Two-way: [(expanded)].
disabled boolean false Disables user interaction and dims the trigger.
