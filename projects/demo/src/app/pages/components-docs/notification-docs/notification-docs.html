Notification Drawer

Real-time event feed drawer featuring categorized grouping, unread tabs, liquid tabs integration, quick mark-read actions, and popup container docking.

Overview

The Notification drawer delivers a complete event notification hub designed to fit smoothly into an <x-liquid-menu-popup> dialog or stand as an independent sidebar card. It automatically groups events into Today and Earlier bands and maintains live unread counters.

Setup & Usage

import { Notification } from '@app/shared/components/notification/notification';
import { LiquidMenuPopup } from '@app/shared/components/liquid-menu-popup/liquid-menu-popup';
import { LiquidMenuTriggerFor } from '@app/shared/components/liquid-menu-popup/liquid-menu-trigger-for.directive';

@Component({
  imports: [Notification, LiquidMenuPopup, LiquidMenuTriggerFor],
  template: `
    <x-liquid-menu-popup #menu="liquidMenu" role="dialog" title="Notifications">
      <app-notification />
    </x-liquid-menu-popup>

    <button type="button" liquidButton="tinted" [liquidMenuTriggerFor]="menu">
      Notifications
    </button>
  `,
})
export class HeaderBar {}
