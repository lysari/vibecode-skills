Chatbot Assistant

Conversational support widget featuring natural query parsing, interactive FAQ suggestion chips, simulated typing indicators, and seamless menu popup dialog docking.

Overview

The Chatbot assistant component offers instant contextual answers from structured knowledge base articles. It features smooth chat arrival animations, reactive suggestion dismissal, auto-scrolling log containers, and standalone or top-layer modal integration.

Setup & Usage

import { Chatbot } from '@app/shared/components/chatbot/chatbot';
import { LiquidMenuPopup } from '@app/shared/components/liquid-menu-popup/liquid-menu-popup';
import { LiquidMenuTriggerFor } from '@app/shared/components/liquid-menu-popup/liquid-menu-trigger-for.directive';

@Component({
  imports: [Chatbot, LiquidMenuPopup, LiquidMenuTriggerFor],
  template: `
    <x-liquid-menu-popup #botMenu="liquidMenu" role="dialog" title="Help Assistant">
      <app-chatbot />
    </x-liquid-menu-popup>

    <button type="button" liquidButton="filled" [liquidMenuTriggerFor]="botMenu">
      Ask Assistant
    </button>
  `,
})
export class HelpWidget {}
