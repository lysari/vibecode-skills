Liquid button

The portal's button. Its fill and its label squash together under the finger and spring back through the other shape — the same press every liquid surface answers with. Three variants, all drawn from one hue, so a button inside a service's section takes that service's accent without being told.

Buttons and links

It goes on the element it is. A <button> stays a button and an <a> stays a link — no role is added either way, so a link that navigates is still announced as one. Give a <button> inside a form its type, since a bare one submits. A disabled link leaves the tab order and swallows its clicks, because an anchor has no disabled of its own.
