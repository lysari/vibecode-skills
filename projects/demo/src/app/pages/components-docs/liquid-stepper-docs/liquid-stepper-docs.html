Liquid stepper

Numbered steps joined by a line that fills up to the one you are on. When the step changes the fill pours along the line the way the tab pill does, and each marker takes its colour as the fill reaches it.

Steps behind the selected one turn to a check. Numbers, checks, colours and the whole look can be swapped out, and a pill variant draws it like the tabs. Arrow keys move focus; Enter or Space picks.

Forms

Give a step its part of a form with [control] and the stepper does the rest: it holds while that control is invalid or still checking, and marks it all touched as it refuses, so the fields show their own errors. No (blocked) handler, no [valid].

Icons

Put liquidStepIcon on any element inside a step and it takes the number's place; liquidStepDone takes the check's. Both take the marker's colour and size. Give a step neither and you get the number and the tick.

Colour

Everything is a --liquid-stepper-* custom property, so a class makes a theme. Set --liquid-stepper-color on a single step to colour just that one. --liquid-stepper-fill-color colours the line alone and takes a gradient, laid along the whole line, so the colour changes as it fills.
