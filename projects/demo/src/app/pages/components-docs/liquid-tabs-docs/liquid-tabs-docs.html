Liquid tabs

A segmented bar whose white pill pours from one tab to the next. The tabs are your own elements — a count or an icon sits inside them as it would anywhere — and the pill is measured off the selected one, so tabs of any width work.

Panels

A liquidTabPanel can sit anywhere, so it names its bar with liquidTabPanelFor. It is hidden while its tab is not selected, and the tabs and panels point aria-controls and aria-labelledby at each other.

Content

A panel without a value is shared. Put each tab's content in an ng-template liquidTabContent inside it and it is built only while its tab is selected. Switching crossfades with a blur — the old content drifts away from the tab picked while the new one drifts in from its side — and the panel eases to the new height.

Options

Default and persist

With nothing bound, default picks the starting tab. Given a persist key the bar remembers its selection and starts there next time — pick one, leave the page and come back.

value: {{ range() }}

Stretch

The tabs share the width equally and the bar fills its container.

Manual activation and disabled

With activation="manual" the arrow keys only move focus; Enter or Space selects. A disabled tab is skipped by both, and disabled on the bar turns every tab off at once. 

{{ optionsSetup }}

Vertical

orientation="vertical" stacks the tabs; the up and down arrows move between them, and the content drifts along the same axis.
