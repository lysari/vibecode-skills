Liquid autocomplete

A select whose list is a search. The field grows a liquid popup out of its own box; the arrow keys move the active row while the focus stays in the search, and the matched text is marked up. Its API is a select's: any array of options, and a value that is one of them.

Search and groups

From seven options up the popup carries a search field; it matches the label and the caption. groupWith lists the options under headings, in the order they are first seen, and iconWith gives each a tile — the icon names are the caller's to register.

Option template

An ng-template liquidAutocompleteOption replaces the text of each row. The row around it — the highlight, the check, the icon tile — stays the list's. The template is handed the option, and whether it is selected or active. The option arrives as unknown — the directive cannot see the field's options — so cast it once with a typed helper.

Forms

It is a form control: [formControl], formControlName and ngModel all work, disable() reaches it, and the control is marked touched when the popup closes. The error state is still yours to bind, through invalid.
