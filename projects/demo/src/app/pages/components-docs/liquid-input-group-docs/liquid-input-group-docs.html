Liquid Input Group

Combines multiple input segments into a cohesive, uninterrupted container with unified labels, focus rings, and validation feedback.

Overview

The LiquidInputGroup component allows phone numbers, network endpoints, dates, and split keys to appear within a single pill container, separated by hairline dividers. Reaching capacity automatically advances focus to the next field.
