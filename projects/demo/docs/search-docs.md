# Search Documentation Page

`src/app/pages/components-docs/search-docs/` — Interactive workshop documentation for the `Search` component.

## Page Structure

- **Overview (`#overview`)**: Component introduction with live in-page standalone search demonstration.
- **Playground (`#playground`)**: Interactive testing sandbox to tweak placeholder strings, toggle recent history caching, view active items, and inspect the reactive `playMarkup()` snippet.
- **Contexts & Overlays (`#sizes`)**: Compares the modal command palette workflow (anchored inside `LiquidMenuPopup`) against embedded in-flow sidebar navigation.
- **Setup (`#setup`)**: Code examples demonstrating both standalone combobox usage and `LiquidMenuPopup` popup anchoring.
- **API Reference (`#api`)**: Specifications for inputs, outputs, and default configuration options.
