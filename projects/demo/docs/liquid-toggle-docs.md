# Liquid Toggle Documentation Page

`src/app/pages/components-docs/liquid-toggle-docs/` — workshop page providing live playground, size hierarchy, and API reference for `LiquidToggle`.

## Sections

- **Overview (`#overview`)**: Component summary with immediate interactive preview.
- **Playground (`#playground`)**: Interactive testing bed toggling active state, fill mode (`track` vs `thumb`), height scaling, disabled state, and validation error messages with live markup generation.
- **Sizes (`#sizes`)**: Size comparisons showing Compact (`22px`), Default (`28px`), and Large (`36px`) variants.
- **Setup (`#setup`)**: Code snippets for standalone component import, direct binding, and Reactive Forms usage.
- **API (`#api`)**: Properties, events, and CSS custom variables specification table.
