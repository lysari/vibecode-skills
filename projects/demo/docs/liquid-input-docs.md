# Liquid Input Documentation Page

`src/app/pages/components-docs/liquid-input-docs/` — workshop page providing live playground, size hierarchy, and API reference for `LiquidInput`.

## Sections

- **Overview (`#overview`)**: Component summary with immediate interactive preview.
- **Playground (`#playground`)**: Interactive testing suite configuring type (text, password, email), height, clear button, reveal toggle, disabled state, and simulated validation errors.
- **Sizes (`#sizes`)**: Size comparisons showing Compact (`36px`), Default (`44px`), and Large (`52px`) variants.
- **Setup (`#setup`)**: Code snippets for standalone component import and two-way binding.
- **API (`#api`)**: Properties, events, and CSS custom variables specification table.
