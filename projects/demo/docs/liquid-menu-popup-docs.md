# Liquid Menu Popup Documentation Page

`src/app/pages/components-docs/liquid-menu-popup-docs/` — workshop page providing interactive demonstrations, size hierarchy, and API reference for `LiquidMenuPopup`.

## Sections

- **Overview (`#overview`)**: Component summary with immediate interactive trigger and action items.
- **Playground (`#playground`)**: Interactive testing suite adjusting menu role (`menu` vs `dialog`), overlay backdrop, initial focus behavior, and real-time execution feedback.
- **Sizes (`#sizes`)**: Size comparisons showing Compact (`--menu-radius: 12px`) and Standard variants.
- **Setup (`#setup`)**: Code snippets for standalone component import and trigger-to-popup linking.
- **API (`#api`)**: Properties, events, and CSS custom variables specification table.
