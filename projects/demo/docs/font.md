# Font

`src/styles/_font.scss` — the font stack, weights and type scale.

## How the values were made

Each size was measured from the reference image's text glyphs and cap heights, matching baseline, letter spacing, and line heights.

## Type scale

| Role | Size | Line | Weight | Tracking | Reference text |
| ---- | ---- | ---- | ------ | -------- | -------------- |
| `h1` | 28px | 34px | bold | −0.5px | "Monitoring & Insights" |
| `h2` | 19px | 24px | bold | −0.3px | "Resource Configuration", "Transaction Conflicts" |
