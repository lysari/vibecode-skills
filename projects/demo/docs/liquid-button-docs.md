# Liquid Button Documentation Page

`src/app/pages/components-docs/liquid-button-docs/` — documentation, live playground, size demonstrations, and API tables for `LiquidButton`.

## Sections

- **Overview (`#overview`)**: Component description and inline variant previews.
- **Playground (`#playground`)**: Interactive control suite adjusting variant, block mode, disabled state, radius, and padding custom properties, accompanied by live markup generator and action click log.
- **Sizes (`#sizes`)**: Size comparisons showing compact, default, large, and block configurations.
- **Variants (`#variants`)**: Showcase of `filled`, `tinted`, `plain`, and anchor variants.
- **Setup (`#setup`)**: Code examples demonstrating standalone imports and template bindings.
- **API (`#api`)**: Parameter specification and CSS custom property tables.
