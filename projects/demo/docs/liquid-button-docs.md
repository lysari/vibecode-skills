# Liquid Button Documentation Page

`src/app/pages/components-docs/liquid-button-docs/` — documentation, live playground, size demonstrations, and API tables for `LiquidButton`.

## Sections

- **Overview (`#overview`)**: Component description, inline variant previews, and icon-only button preview.
- **Playground (`#playground`)**: Interactive control suite adjusting variant, block mode, icon-only mode, disabled state, radius, and padding custom properties, accompanied by live markup generator and action click log.
- **Buttons and links (`#elements`)**: Demonstrations of `<button>`, `<a>`, disabled states, block mode, and icon-only buttons.
- **Sizes (`#sizes`)**: Size comparisons showing compact, default, large, and block configurations.
- **Variants (`#variants`)**: Showcase of `filled`, `tinted`, `plain`, and anchor variants.
- **Colour (`#colour`)**: Demonstrates custom `--liquid-button-hue` themes and surface overrides.
- **Setup (`#setup`)**: Code examples demonstrating standalone imports and template bindings.
- **API (`#api`)**: Parameter specification and CSS custom property tables.
