# Liquid Input Group Documentation Page

`src/app/pages/components-docs/liquid-input-group-docs/` — workshop page providing interactive multi-segment demonstrations, size hierarchy, and API reference for `LiquidInputGroup`.

## Sections

- **Overview (`#overview`)**: Component summary with immediately interactive phone number example.
- **Playground (`#playground`)**: Interactive testing suite with URL/Protocol/Domain/Port segments, height scaling, disabled state, and simulated validation errors.
- **Sizes (`#sizes`)**: Size comparisons showing Compact (`36px`), Default (`44px`), and Large (`52px`) variants.
- **Setup (`#setup`)**: Code snippets for standalone component import and composite dictionary value binding.
- **API (`#api`)**: Properties, events, and CSS custom variables specification table.
