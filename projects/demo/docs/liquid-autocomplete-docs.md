# Liquid Autocomplete Documentation Page

`src/app/pages/components-docs/liquid-autocomplete-docs/` — Interactive workshop documentation for the `LiquidAutocomplete` component.

## Page Structure

- **Overview (`#overview`)**: Demonstrates standard regional cloud zone selection with category grouping and instant search filtering.
- **Playground (`#playground`)**: Interactive configuration sandbox allowing users to toggle clearable cross buttons, disabled modes, invalid error glows, and review the live reactive `playMarkup()` snippet.
- **Sizes & Grouping (`#sizes`)**: Shows the `LiquidSegment` capability embedding `LiquidAutocomplete` alongside a text input inside `<x-liquid-input-group>`.
- **Setup (`#setup`)**: Code examples demonstrating reactive forms and custom grouping declarations.
- **API Reference (`#api`)**: Specifications for inputs, outputs, and default configuration options.
