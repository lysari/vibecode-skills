# Liquid Toast Documentation Page

`src/app/pages/components-docs/liquid-toast-docs/` — workshop page providing interactive demonstrations, edge positioning, size hierarchy, and API reference for `LiquidToast`.

## Sections

- **Overview (`#overview`)**: Component summary with immediate interactive triggers for success, warning, error, and promise toasts.
- **Playground (`#playground`)**: Interactive testing suite adjusting edge position, timer countdown mode, visible toast count, gap, radius, and auto-dismiss policy.
- **Sizes (`#sizes`)**: Formats comparing compact single-line, default title + description, large actionable, and target-anchored cards with verbal button labels.
- **Setup (`#setup`)**: Code snippets for single toaster mounting and calling `toast.*` APIs.
- **API (`#api`)**: Inputs for `<x-liquid-toaster>` and methods provided on the module-level `toast` store.
