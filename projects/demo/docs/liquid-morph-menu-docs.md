# Liquid Morph Menu Documentation Page

`src/app/pages/components-docs/liquid-morph-menu-docs/` — workshop page providing interactive demonstrations, size hierarchy, and API reference for `LiquidMorphMenu`.

## Sections

- **Overview (`#overview`)**: Component summary with immediately interactive toolbar example.
- **Playground (`#playground`)**: Interactive testing suite with horizontal/vertical orientation switcher, glass pill toggle, and hover suppression.
- **Sizes (`#sizes`)**: Size comparisons showing Compact (`28px`) and Standard (`36px`) variants.
- **Setup (`#setup`)**: Code snippets for standalone component import and directive attachment.
- **API (`#api`)**: Properties, events, and CSS custom variables specification table.
