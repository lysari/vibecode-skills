# Global styles

`src/styles/_global.scss` — element defaults, body wallpaper background, and control resets.

## Background and Layout

- `body` displays the Ghibli mountain landscape wallpaper (`/wallpaper.jpg`), fixed and centered, with 48px padding on desktop matching the floating window offset in the reference screenshot.
- Focus-visible outline is styled with `--color-chart-bar` (blue) and 2px offset for keyboard accessibility.

## Controls and Resets

- Button and input elements have border, background, and font resets.
- Form inputs default to transparent backgrounds with custom placeholder color `--color-text-placeholder`.
