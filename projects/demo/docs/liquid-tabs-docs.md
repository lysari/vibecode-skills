# Liquid Tabs Documentation Page

`src/app/pages/components-docs/liquid-tabs-docs/` — documentation, live playground, size demonstrations, and API tables for `LiquidTabs`.

## Sections

- **Overview (`#overview`)**: Component description and basic tab strip preview.
- **Playground (`#playground`)**: Interactive controls for orientation (horizontal/vertical), stretch, disabled state, container padding, corner radius, and tab inner padding, with live markup generation.
- **Sizes (`#sizes`)**: Compact, default, and large full-width stretched tab bar demonstrations.
- **Panels (`#panels`)**: Live demonstration of `x-liquid-tabs` linked to `liquidTabPanel` containers.
- **Setup (`#setup`)**: Standalone import pattern and template usage.
- **API (`#api`)**: Input/output parameters and CSS custom property tables.
