# Pincode Box Documentation Page

`src/app/pages/components-docs/pincode-box-docs/` — Interactive workshop documentation for the `PincodeBox` component.

## Page Structure

- **Overview (`#overview`)**: Demonstrates standard 6-digit verification code entry with preview.
- **Playground (`#playground`)**: Live interactive configuration with slot length selection (4, 6, 8 digits), dimension sizes (sm, md, lg), security masking, disabled/invalid/loading states, live `playMarkup()` code block, and simulated backend verification with asynchronous wave loading.
- **Sizes (`#sizes`)**: Side-by-side comparison of compact 4-digit mobile verification, standard 6-digit 2FA entry, and prominent 4-digit masked transaction PINs, with verbal button triggers (`Fill Sample PIN`, `Fill Sample OTP`, `Fill Sample Security PIN`).
- **Setup (`#setup`)**: Example template and component imports for reactive forms and event handling.
- **API Reference (`#api`)**: Table of inputs, outputs, and default configuration values.
