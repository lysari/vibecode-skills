# Liquid Slider Documentation Page

`src/app/pages/components-docs/liquid-slider-docs/` — workshop page providing live playground, size demonstrations, and API reference for `LiquidSlider`.

## Sections

- **Overview (`#overview`)**: Component summary with immediate interactive preview.
- **Playground (`#playground`)**: Interactive testing suite adjusting step interval (1, 5, 10), height scaling, ticks rendering, disabled state, and simulated validation errors.
- **Sizes (`#sizes`)**: Size comparisons showing Compact (`38px`), Default (`46px`), and Large (`56px`) variants.
- **Setup (`#setup`)**: Code snippets for standalone component import and two-way value binding.
- **API (`#api`)**: Properties, events, and CSS custom variables specification table.
